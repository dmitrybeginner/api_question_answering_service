# ИНСТРУКЦИЯ ПО ТЕСТИРОВАНИЮ API

## Проект работает! Данные уже есть в базе.

**Доступ к API:**
- При локальном запуске: http://127.0.0.1:8000/
- При запуске через Docker:
  - Через nginx: http://localhost:8080/ (рекомендуется)
  - Прямо через web: http://localhost:8000/


## МЕТОД 1: Через веб-интерфейс Django REST Framework

Это **самый простой способ** - Django предоставляет готовый интерфейс!

### Просмотр списка вопросов

**При локальном запуске:** http://127.0.0.1:8000/questions/
**При запуске через Docker:** http://localhost:8080/questions/ или http://localhost:8000/questions/

**Что вы видите:**
- JSON с данными (3 вопроса с ответами)
- Форму внизу для создания нового вопроса

---

### Создать новый вопрос

**На странице http://127.0.0.1:8000/questions/**

1. Прокрутите страницу **вниз**
2. Найдите форму "HTML form" или "Raw data"
3. В поле `text` введите:
   ```
   Как работает Docker?
   ```
4. Нажмите **POST**

**Результат:** Новый вопрос создан! Вы увидите его данные с ID.

**Примечание:** Вопрос будет привязан к техническому пользователю `anonymous` если вы не авторизованы.


### Просмотреть конкретный вопрос

**При локальном запуске:** http://127.0.0.1:8000/questions/1/
**При запуске через Docker:** http://localhost:8080/questions/1/ или http://localhost:8000/questions/1/

**Что вы видите:**
- Данные вопроса
- Все ответы на него
- Кнопку **DELETE** (красная, справа вверху)


### Удалить вопрос

**На странице http://127.0.0.1:8000/questions/1/**

1. Нажмите красную кнопку **DELETE** (справа вверху)
2. Подтвердите удаление

**Результат:** 
- Вопрос удалён
- Все его ответы удалены автоматически (каскадное удаление)


### Добавить ответ к вопросу

**При локальном запуске:** http://127.0.0.1:8000/questions/2/answers/
**При запуске через Docker:** http://localhost:8080/questions/2/answers/ или http://localhost:8000/questions/2/answers/

1. Прокрутите вниз до формы
2. Заполните:
   - `user_id`: `test-user-123` (любой текст или UUID)
   - `text`: `Это отличный вопрос!`
3. Нажмите **POST**

**Результат:** Ответ создан и привязан к вопросу #2.


### Просмотреть конкретный ответ

**При локальном запуске:** http://127.0.0.1:8000/answers/1/
**При запуске через Docker:** http://localhost:8080/answers/1/ или http://localhost:8000/answers/1/

**Что вы видите:**
- Данные ответа
- Кнопку **DELETE**

---

### Удалить ответ

**На странице http://127.0.0.1:8000/answers/1/**

1. Нажмите красную кнопку **DELETE**
2. Подтвердите

**Результат:** Ответ удалён (вопрос остался).



## МЕТОД 2: Через Swagger UI

**При локальном запуске:** http://127.0.0.1:8000/swagger/
**При запуске через Docker:** http://localhost:8080/swagger/ или http://localhost:8000/swagger/

### Как использовать:

1. Выберите эндпоинт (например, `POST /questions/`)
2. Нажмите **Try it out**
3. Введите данные в JSON формате
4. Нажмите **Execute**
5. Увидите результат внизу


## МЕТОД 3: Через Django Admin

**При локальном запуске:** http://127.0.0.1:8000/admin/
**При запуске через Docker:** http://localhost:8080/admin/ или http://localhost:8000/admin/

1. Войдите (admin / admin123)
2. Выберите **Questions** или **Answers**
3. Создавайте, редактируйте, удаляйте через GUI
